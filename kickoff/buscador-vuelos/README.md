# Buscador de Vuelos — Cierre del kickoff PIP

Actividad de cierre del kickoff del taller PIP (Proyecto Ingeniería,
FIUBA). A diferencia de las demos anteriores del día, esta la resuelven las
escuadras: hay que completar la función de filtrado de un buscador de vuelos
combinando código propio y ayuda de un chatbot de IA (vibecoding).

> Nota: esta app es una ambientación ficticia con fines educativos. No
> representa sistemas, datos ni procesos reales de Aerolíneas Argentinas ni
> de ninguna otra empresa.

## Empezar acá

1. Leé [`CONSIGNA.md`](./CONSIGNA.md) — qué hay que hacer y cómo se prueba.
2. Si te trabás con JS, [`TEORIA.md`](./TEORIA.md) tiene lo mínimo necesario.
3. Antes de escribirle a la IA, [`GUIA_IA.md`](./GUIA_IA.md) tiene tips para
   pedir bien las cosas y revisar lo que te devuelva.

## Stack

HTML/CSS/JS plano, sin build ni dependencias. Toda la lógica a completar
está en un único archivo: [`app.js`](./app.js).

## Cómo correr el proyecto

**Sandbox (recomendado, sin instalar nada):**

- CodeSandbox: importá `github.com/ProyectoIngenieria-fiuba/PIProgramando`
  y abrí la carpeta `kickoff/buscador-vuelos`.
- StackBlitz: `stackblitz.com/github/ProyectoIngenieria-fiuba/PIProgramando/tree/main/kickoff/buscador-vuelos`

**Local:**

```bash
git clone https://github.com/ProyectoIngenieria-fiuba/PIProgramando.git
cd PIProgramando/kickoff/buscador-vuelos
```

Abrí `index.html` directo en el navegador, o serví la carpeta:

```bash
npx serve .
```

No hace falta `npm install`: no hay dependencias.
